# Images

Screenshots use the sample data in `scripts/preview.mjs` (no real chats).

1. `npm run build && node scripts/preview.mjs`
2. Screenshot `.superpowers/preview/dark.html?t=<tab>` (`?t=welcome` for the welcome screen) at 340 × 820 and 2× scale.
3. `hero.jpg` is `hero.html` rendered at 1280 × 720 and 2× scale.

`chats-light.png` and `usage-light.png` come from `light.html` in the same way. `welcome.png` uses `?t=welcome`.
